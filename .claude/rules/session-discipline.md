# session-discipline

세션 맥락 관리 룰. 한 세션 안에서 컨텍스트가 오염되거나 같은 질문이 반복되는 것을 방지한다.

- 세션 정의: 한 번의 연속된 대화 단위. 터미널 창과 1:1 아니다. 같은 창 안에서도 새 세션을 시작할 수 있고, 다른 창에서 `--resume` 으로 이어 받을 수도 있다. 판단 기준은 컨텍스트 누적량.
- 컨텍스트 사용량이 체감 25% 를 넘으면 새 세션 또는 handoff 를 사용자에게 제안한다. 본문 작업을 강제로 새 세션으로 끊지는 않는다.
- 같은 질문을 두 번 받으면 그 시점에서 룰 또는 skill 보강 후보로 기록한 뒤 진행한다. 기록 없이 답만 반복하지 않는다.
- 작업 종료 시 다음 세션이 이어받을 1, 2줄 handoff 노트를 사용자에게 제안한다. 사용자가 거절하면 거기서 멈춘다.
- 룰/skill 이 오래되어 보이거나 사용처가 사라졌다 싶으면 정리 후보로 기록한다. 자발적으로 삭제하지 않는다.
